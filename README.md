# Хранители планеты

Семь разных игр по окружающему миру для 4 класса. Хаос-король растащил знания по мирам, а ребёнок возвращает их как игровые трофеи: щит, скорость, комбо, выстрел. Это не общая викторина: у каждого мира свой герой, управление, палитра, музыка и босс.

## Как запустить

```bash
npm install
npm run dev
```

Сборка автономной версии:

```bash
npm run build
npm run preview
```

Игра удобна от ширины 1024 пикселей, с мышью и пальцем. Прогресс пишется в браузер этого компьютера. В каждом мире ровно три уровня: следующий открывается после победы. Пауза — кнопка и Esc. Перед игрой короткое «Как играть». Разделы штаба: Миры, Энциклопедия, Испытание, Герой, Награды, Для учителя. Учитель открывает кабинет примером 7 + 8. Учебные формулировки собраны в `src/data/curriculum.js`.

## Миры

| Мир | Как играть |
| --- | --- |
| Безопасный город | Страж и пёс. Поступки на улице, дома и в сети, потом король опасностей. |
| Космический гонщик | 3D-ракета. Веди пальцем, собирай планеты, обойди чёрную дыру по маякам. |
| Лесная оборона | Башни. Трава кормит зайца, заяц — лису. Неверная цепь вянет. |
| Тело-подлодка | Вид сбоку. Стреляй витаминами по микробам и доберись до вируса. |
| Большой забег | Бег. Прыжок и скольжение по зонам, на финише ворота со зверями. |
| Машина времени | Сачок. Лови события своей эпохи, в бою — по порядку лет. |
| Эко-патруль | Робот на площадке. Крупный мусор кладут в бак своего цвета. Птенца спасают. |

## Как добавить содержание

Карточки открытий лежат в `src/rewards.js`. Правила конкретного мира — в `src/worlds/<мир>/index.js`. Общими остаются только глобус, сохранения и альбом.
